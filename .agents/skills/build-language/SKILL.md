# build-language

Lire et appliquer [le skill language](../language/SKILL.md) à la demande qui accompagne cette commande. Cette entrée est un alias : le skill cible reste la source de vérité, avec son périmètre, ses règles et ses validations. Ne pas lancer une compilation uniquement parce que le nom commence par build.

Si aucune tâche n'est fournie, décrire brièvement le workflow et demander le périmètre souhaité avant toute modification.
